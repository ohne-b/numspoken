## The last three tens

In France, 70 is sixty plus ten: _soixante-dix_. 80 is four twenties:
_quatre-vingts_. 90 adds ten to that: _quatre-vingt-dix_.

21, 31, 41, 51 and 61 use _et un_. 71 uses _et onze_, but 81 and 91
have no _et_: _quatre-vingt-un_, _quatre-vingt-onze_.

## Final s

Keep the “s” in exactly 80, _quatre-vingts_. Drop it when another number
follows: _quatre-vingt-deux_.

The same rule applies to multiplied hundreds: _deux cents_, but
_deux cent trois_. Before _mille_, neither takes “s”: _deux cent mille_.

## Belgian French

Belgium uses _septante_ and _nonante_. 80 is still _quatre-vingts_.
Choose Belgium in settings to practise these forms.

| Number | French          |
| -----: | --------------- |
|     70 | septante        |
|     71 | septante et un  |
|     80 | quatre-vingts   |
|     81 | quatre-vingt-un |
|     90 | nonante         |
|     91 | nonante et un   |

## Hyphens

The chart uses traditional spacing. The 1990 spelling recommendations
also allow hyphens throughout a compound number. Forgiving spelling
accepts either spacing pattern.
