## Place values

21 is two tens and one: _二十一_. 100 is _一百_ and 1,000 is _一千_.
There are no spaces between the characters.

At the start of 10–19, omit the initial _一_: _十_, _十一_, _十二_.

## Empty places

Use _零_ when a place is skipped: 101 is _一百零一_, and 1,001 is
_一千零一_. Several consecutive empty places need only one _零_.

## Groups of ten thousand

_万_ means 10,000. Read 1,234,567 as 123 ten-thousands, then 4,567:
_一百二十三万四千五百六十七_. This grouping differs from English thousands.

## Scripts

The main chart uses simplified characters. The Taiwan setting uses
traditional characters. The value and word order stay the same.

|    Number | Simplified                 | Traditional                |
| --------: | -------------------------- | -------------------------- |
|        10 | 十                         | 十                         |
|        12 | 十二                       | 十二                       |
|    10,000 | 一万                       | 一萬                       |
| 1,234,567 | 一百二十三万四千五百六十七 | 一百二十三萬四千五百六十七 |

## Everyday and financial characters

The chart uses everyday _一_, _二_, _三_. Financial forms such as
_壹_, _贰_, _叁_ are also accepted in the matching script. Use _二_
in these exercises; spoken Mandarin also uses _两_ in some counting contexts.
